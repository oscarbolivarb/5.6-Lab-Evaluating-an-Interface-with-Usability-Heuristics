Heuristic evluation of the Airbnb Interface
5.6 Lab | Evaluating an Interface with Usability Heuristics

Interface Overview
Interface Name: Airbnb  
URL: https://www.airbnb.com
Airbnb is an online platform that allows users to search for properties and book them for a short term, they have properties around the world. The users are people who are looking to travel to places to stay in properties that other people own such as houses, apartments, boats and more. The main purpose of the website is to help users find accommodations, communicate with hosts and complete reservations. 
Heuristic Evaluation Results
1.	Visibility of System Status
Usability Issue
When users apply multiple search filters during a search such as price, amenities and property type, it becomes difficult to understand how these filters affect the search result.
Location 
This happens in the search results page after selecting multiple filters such as price range, amenities and property type.
Why is this a problem
This heuristic states that the system should always keep users informed about what is happening. When multiple filters are active, users might not remember which filters they have selected and this is why certain listings are no longer showing up. This increases cognitive load because users have to think more about the search process. 
User Impact
Users may become confused or even frustrated if they believe listings have disappeared for no reason. This can also make searching for accommodations take longer.
Proposed Improvement    
Airbnb could display a more detailed summary to show how these active filters affects the number of available listings. 
2.	Match Between System and the Real World 
Usability Issue 
The nightly price shown in the search results does not always match the total amount users will pay after fees and taxes that are added. 
Location
This happens in the search result page and property listing pages.  
Why is this a problem 
Most users think about the total cost of a trip rather than just the nightly rate. This shows only part of the total cost at the beginning and it does not completely match how people naturally think when planning a trip.
User Impact
Users may feel disappointed and frustrated when they see the final price that is increased during checkout and this can reduce the trust in the platform.
Proposed Improvement
By displaying the total estimated amount it become clear to the users so they would know what they are going to pay throughout the search and booking process 
3.	User Control and Freedom
Usability Issue 
Users can accidentally change dates or search settings while browsing listings and they might not realize it right away. 
Location 
The search pages and the listing navigation process 
Why is this a problem 
Users should have an easy way to undo mistakes and if the search settings change by accident, then the users might have trouble returning to the previous search.
User Impact
This can waste time and make users frustrated because they may need to repeat searches or reapply filters. 
Proposed Improvement
Allow users to quickly restore their previous search settings by adding an easy to see undo button. 

4.	Consistency and Standards 
Usability Issue 
Important information is not always displayed in the exact same way across different listings.  
Location 
Individual property listing pages
Why is this a problem 
Users expect similar information to appear in consistent locations throughout the website, when details such as cancellation policies or house rules appear in different places usually users have to spend more time searching for them. 
User Impact
Users may miss out on important information or become confused when comparing multiple listings.
Proposed Improvement
A standardized layout regarding important information should appear in the same location on every single listing page. 
5.	Recognition Rather Than Recall
 Usability Issue 
Users often need to remember information from one property while they are looking at another property. 
Location 
The search results and property comparison process. 
Why is this a problem 
This heuristic focuses on reducing the amount of information that users have to remember. When users are comparing listings, users must go back and forth between pages to remember prices, amenities and ratings.
User Impact
This makes comparing properties more difficult and increases the time needed to make a decision.
Proposed Improvement
By creating a side by side comparison feature this would allow users to be able to compare multiple listings at the same time. 
Reflection  
The heuristic that helped identify usability issues was the Recognition Rather Than Recall. While users use Airbnb they need to compare many different properties and this often means remembering information from previous viewed listings. Here a comparison feature would reduce the amount of information the user needs to remember in order to make their decision making process easier.   
One limitation of the heuristic evaluation is that it is based on the evaluator’s opinion instead of feedback from real users. An issue that seems important to an evaluator may not actually cause problems for the user. 
User testing allows designers to see how people really interact with the system and this can reveal issues that might have not been found during a heuristic evaluation. For this reason, the heuristic evaluation is valuable since it shows potential usability issues, especially when it’s combined with user based testing.
